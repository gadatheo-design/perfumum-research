# Interactions Moléculaires Tabac-Cannabis-Parfum — PERFUMUM

## 1. SYNERGIES CANNABINOÏDES-TERPÈNES (Effet Entourage)

### 1.1 Concept de l'Effet Entourage

L'effet entourage, décrit par Russo (2011), désigne la synergie entre les phytocannabinoides et les terpénoïdes du cannabis. Les terpènes ne sont pas de simples composés aromatiques — ils modulent activement les effets des cannabinoïdes (THC, CBD) via plusieurs mécanismes :

| Mécanisme | Description | Exemple |
|-----------|-------------|---------|
| **Multi-cibles** | Action sur plusieurs récepteurs simultanément | β-caryophyllène agit sur CB2 |
| **Pharmacocinétique** | Amélioration de la biodisponibilité | Myrcène facilite passage BHE |
| **Modulation adverse** | Réduction des effets secondaires | CBD réduit anxiété du THC |
| **Résistance bactérienne** | Synergie antimicrobienne | Pinène + CBD vs MRSA |

### 1.2 Terpènes Clés et Leurs Synergies

| Terpène | Synergie avec THC | Synergie avec CBD | Applications |
|---------|-------------------|-------------------|--------------|
| **Myrcène** | Potentialise effets sédatifs | Renforce anti-inflammatoire | Relaxation, douleur |
| **Limonène** | Réduit anxiété | Améliore humeur | Antidépresseur |
| **α-Pinène** | Contrecarre perte mémoire | Bronchodilatateur | Clarté mentale |
| **Linalol** | Renforce analgésie | Anxiolytique | Calmant |
| **β-Caryophyllène** | Agoniste CB2 direct | Anti-inflammatoire | Douleur, inflammation |

## 2. HASHISHENE — TERPÈNE UNIQUE DU HASHISH

### 2.1 Découverte et Caractéristiques

Le hashishene (5,5-diméthyl-1-vinylbicyclo[2.1.1]hexane) a été découvert en 2014 par des chercheurs de l'Université de Nice. C'est un isomère du β-myrcène (même formule C₁₀H₁₆) formé par photo-oxydation.

| Propriété | Valeur |
|-----------|--------|
| **Formule** | C₁₀H₁₆ |
| **Nom IUPAC** | 5,5-diméthyl-1-vinylbicyclo[2.1.1]hexane |
| **Concentration dans hash marocain** | Jusqu'à 14.9% des terpènes |
| **Arôme** | Terreux, floral, doux |
| **Formation** | Photo-oxydation du myrcène |

### 2.2 Processus de Formation

Le hashishene se forme lors du séchage traditionnel marocain :
1. Exposition aux UV solaires
2. Présence d'oxygène
3. Réarrangement moléculaire du myrcène
4. Catalyseurs photosensibilisants (non identifiés)

Ce processus explique pourquoi le hash marocain a un profil aromatique distinct des fleurs séchées conventionnellement.

## 3. CONSTITUANTS AROMATIQUES DU TABAC

### 3.1 Familles de Composés (d'après Mookherjee & Wilson, 1990)

Le tabac contient plus de 3000 composés volatils et non-volatils identifiés :

| Famille | Exemples | Rôle aromatique |
|---------|----------|-----------------|
| **Hydrocarbures** | Limonène, caryophyllène | Base aromatique |
| **Acides** | Isovalérique, caproïque | Notes animales |
| **Phénols** | Thymol, eugénol | Notes épicées |
| **Aldéhydes** | Vanilline, benzaldéhyde | Notes sucrées |
| **Lactones** | Damascones, ionones | Notes florales |
| **Composés soufrés** | Alkyl sulfides | Notes terreuses |
| **Terpénoïdes** | Cédrol, cédrène | Notes boisées |

### 3.2 Terpénoïdes Clés du Tabac

| Composé | Concentration | Arôme | Aussi présent dans |
|---------|---------------|-------|-------------------|
| **β-Caryophyllène** | Variable | Poivre, bois | Cannabis, clou de girofle |
| **Cédrène** | 22-26% (huile cèdre) | Boisé | Bois de cèdre |
| **Cédrol** | 26-32% (huile cèdre) | Boisé, doux | Bois de cèdre |
| **Limonène** | Trace | Agrumes | Citrus, cannabis |
| **Damascones** | Trace | Rose, fruité | Rose, thé |
| **Ionones** | Variable | Violette | Violette, iris |

### 3.3 Conversion du Caryophyllène en Matériaux de Parfumerie

Le β-caryophyllène du tabac peut être converti en composés aromatiques utiles :
- **Oxyde de caryophyllène** (5) — odeur de tabac riche
- **Mélange d'alcools** (6) — odeur douce, boisée, poivrée

## 4. INTERACTIONS PARFUM-TABAC-CANNABIS

### 4.1 Molécules Communes (Pont Aromatique)

Ces molécules sont présentes dans les trois domaines et créent des synergies naturelles :

| Molécule | Tabac | Cannabis | Parfumerie | Synergie potentielle |
|----------|-------|----------|------------|---------------------|
| **β-Caryophyllène** | ✓ | ✓ | ✓ | Notes épicées-boisées |
| **Limonène** | ✓ | ✓ | ✓ | Fraîcheur agrumes |
| **Linalol** | ✓ | ✓ | ✓ | Notes florales |
| **Géraniol** | ✓ | ✓ | ✓ | Notes rose |
| **Eugénol** | ✓ | Trace | ✓ | Notes clou de girofle |
| **Vanilline** | ✓ | - | ✓ | Douceur sucrée |
| **Damascones** | ✓ | - | ✓ | Notes rose-fruité |
| **Ionones** | ✓ | - | ✓ | Notes violette |

### 4.2 Principes d'Aromatisation du Tabac

L'industrie du tabac utilise deux techniques principales :

**Casing (Sauce de base)**
- Appliqué avant le séchage final
- Contient : sucres, miel, réglisse, cacao, fruits
- Pénètre profondément dans la feuille
- Représente 5-20% du poids final

**Top Dressing (Aromatisation finale)**
- Appliqué après le casing
- Contient : huiles essentielles, absolus, molécules synthétiques
- Responsable de l'arôme de pochette
- Représente 0.5-3% du poids final

### 4.3 Molécules de Parfumerie pour Tabac Aromatisé

| Catégorie | Molécules | Effet sur le tabac |
|-----------|-----------|-------------------|
| **Vanillés** | Vanilline, éthyl vanilline | Douceur, rondeur |
| **Floraux** | Linalol, géraniol, nérol | Légèreté, fraîcheur |
| **Épicés** | Eugénol, cinnamaldéhyde | Chaleur, profondeur |
| **Boisés** | Cédrol, vétiver, santal | Sophistication |
| **Ambrés** | Labdanum, benjoin | Richesse, fixation |
| **Musqués** | Muscs blancs | Sensualité, tenue |

## 5. SYNERGIES TERPÉNIQUES TABAC-CANNABIS

### 5.1 Profils Terpéniques Comparés

| Terpène | Tabac Virginia | Tabac Oriental | Cannabis Indica | Cannabis Sativa |
|---------|----------------|----------------|-----------------|-----------------|
| Myrcène | Faible | Faible | **Élevé** | Moyen |
| Limonène | Trace | Moyen | Moyen | **Élevé** |
| Pinène | Trace | Faible | Moyen | Moyen |
| Caryophyllène | Moyen | **Élevé** | **Élevé** | Moyen |
| Linalol | Faible | Moyen | Moyen | Moyen |
| Humulène | Faible | Moyen | Moyen | Faible |

### 5.2 Interactions Potentielles lors du Mélange

Lorsque tabac et cannabis sont mélangés (pratique courante en Europe), plusieurs interactions se produisent :

| Interaction | Mécanisme | Effet |
|-------------|-----------|-------|
| **Synergie terpénique** | Terpènes communs se renforcent | Profil aromatique enrichi |
| **Modulation nicotine-THC** | Nicotine modifie absorption THC | Effet psychoactif modifié |
| **Combustion différentielle** | Températures de vaporisation différentes | Libération séquentielle |
| **Effet entourage étendu** | Terpènes tabac + cannabinoïdes | Nouvelles synergies |

### 5.3 Températures de Vaporisation Clés

| Composé | Point d'ébullition | Température optimale |
|---------|-------------------|---------------------|
| THC | 157°C | 170-190°C |
| CBD | 160-180°C | 180-200°C |
| Myrcène | 167°C | 166-168°C |
| Limonène | 176°C | 175-178°C |
| Linalol | 198°C | 195-200°C |
| Caryophyllène | 119°C | 118-120°C |
| Nicotine | 247°C | 200-230°C (fumée) |

## 6. APPLICATIONS POUR PERFUMUM

### 6.1 Axes de Recherche Proposés

1. **Création d'accords "fumés"** combinant terpènes du tabac et du cannabis
2. **Étude des synergies** entre molécules de parfumerie et profils terpéniques
3. **Développement de profils olfactifs** inspirés du hashish traditionnel
4. **Exploration des damascones** comme pont tabac-parfumerie
