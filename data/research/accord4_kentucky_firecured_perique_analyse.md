## I. ANALYSE PROFILS TERPÉNIQUES HASCHISCH (Hassan et al. 2023)

### A. Résultats Article Hassan et al. (2023)

**Source** : Hassan, S.S.M. et al. (2023) - "Characterization of some 'hashish' samples in the Egyptian illicit trafficking market"

**Échantillons** : 3 échantillons haschisch (A, B, C) saisis marché illicite Égypte, origine présumée Maroc/Liban/Algérie

**Méthode** : TSP/GC/MS (Thermal Separation Probe + Gas Chromatography-Mass Spectrometry)

---

### B. Terpènes Détectés (23 terpènes)

**Terpènes en proportions élevées** :
1. **Caryophyllene** (β-Caryophyllène) : Épicé-poivré-boisé
2. **Humulene** (α-Humulène) : Boisé-terreux-houblon
3. **Caryophylla-4(12),8(13)-dien-5α-ol** : Sesquiterpène oxydé
4. **Isoaromadendrene epoxide** : Sesquiterpène oxydé
5. **Alloaromadendrene oxide-(1)** : Sesquiterpène oxydé

**Autres terpènes détectés** :
- **α-Pinene** : Pin-frais-alerte
- **Hashishene** (5,5-dimethyl-1-vinylbicyclo[2.1.1]hexane) : Terreux-musqué-haschisch (terpène unique haschisch marocain)
- Bergamiol, Nerolidol, Caryophyllene oxide, etc.

---

### C. Conclusion Article

**Similitudes qualitatives** : Les 3 échantillons (A, B, C) contiennent presque les mêmes terpènes (23 terpènes communs)

**Différences quantitatives** : Proportions variables selon origine (Maroc/Liban/Algérie)

**Profil terpénique commun** (Maroc, Liban, Algérie) :
- **Caryophyllene** (épicé-poivré-boisé) : Dominant
- **Humulene** (boisé-terreux-houblon) : Dominant
- **Sesquiterpènes oxydés** : Proportions élevées
- **α-Pinene** (pin-frais-alerte) : Présent
- **Hashishene** (terreux-musqué-haschisch) : Présent (signature marocaine)

## II. COMPATIBILITÉ PERIQUE AVEC HASCHISCH LIBANAIS/ALGÉRIEN

### A. Profil Terpénique Haschisch Libanais/Algérien (Hassan et al. 2023)

**Terpènes dominants** :
- **Caryophyllene** (épicé-poivré-boisé)
- **Humulene** (boisé-terreux-houblon)
- **Sesquiterpènes oxydés** (caryophylla-dien-ol, isoaromadendrene epoxide, alloaromadendrene oxide)
- **α-Pinene** (pin-frais-alerte)

**Profil aromatique** : **Épicé-poivré-boisé-terreux-pin**

---

### B. Profil Perique

**Composition chimique** :
- Nicotine : 3-5% (fort-nicotiné-puissant)
- Acides organiques : 5-10% (acidulé-fermenté-vinaigré)
- Composés fermentés : 2-5% (fermenté-fruité-prune-figue)
- Pyrazines : 0.02-0.08% (noisette-grillé-fumé-intense)
- Composés phénoliques : 1-3% (épicé-poivré-piquant)

**Profil aromatique** : **Fermenté-fruité-prune-figue-épicé-poivré-terreux-fumé-fort-nicotiné-puissant**

---

### C. Synergies Perique + Haschisch Libanais/Algérien

#### Synergie 1 : Composés phénoliques (Perique) + Caryophyllene (Haschisch)

**Composés** :
- Composés phénoliques (Perique) : Épicé-poivré-piquant
- Caryophyllene (Haschisch) : Épicé-poivré-boisé

**Synergie** : **Épicé-Poivré-Intense-Piquant**
- Type : Synergie synergique
- Effet : Amplification notes épicé-poivré, profil très piquant et intense
- Caractéristique : Profil épicé-poivré (Perique + Haschisch) très prononcé

---

#### Synergie 2 : Composés fermentés (Perique) + Humulene (Haschisch)

**Composés** :
- Composés fermentés (Perique) : Fermenté-fruité-prune-figue
- Humulene (Haschisch) : Boisé-terreux-houblon

**Synergie** : **Fermenté-Fruité-Boisé-Terreux**
- Type : Synergie modulante
- Effet : Composés fermentés (Perique) modulent notes boisé-terreux (Humulene), profil fermenté-fruité-boisé
- Caractéristique : Profil fermenté-prune-figue + notes boisé-terreux-houblon, complexité aromatique

---

#### Synergie 3 : Pyrazines (Perique) + Sesquiterpènes oxydés (Haschisch)

**Composés** :
- Pyrazines (Perique) : Noisette-grillé-fumé-intense
- Sesquiterpènes oxydés (Haschisch) : Boisé-terreux-oxydé

**Synergie** : **Noisette-Grillé-Fumé-Boisé-Terreux**
- Type : Synergie additive
- Effet : Renforcement mutuel notes noisette-grillé-fumé + boisé-terreux-oxydé
- Caractéristique : Profil noisette-fumé (Perique) + notes boisé-terreux-oxydé (Haschisch), profondeur

---

#### Synergie 4 : Acides organiques (Perique) + Caryophyllene (Haschisch)

**Composés** :
- Acides organiques (Perique) : Acidulé-fermenté-vinaigré
- Caryophyllene (Haschisch) : Épicé-poivré-boisé

**Synergie** : **Acidulé-Fermenté-Épicé-Poivré**
- Type : Synergie synergique
- Effet : Amplification notes acidulé-fermenté + épicé-poivré, profil piquant et complexe
- Caractéristique : Profil acidulé-fermenté (Perique) + notes épicé-poivré (Haschisch), complexité maximale

---

### D. Évaluation Compatibilité

**Compatibilité** : **EXCELLENTE** ⭐⭐⭐

**Raisons** :
1. **Synergies épicé-poivré** : Composés phénoliques (Perique) + Caryophyllene (Haschisch) → Profil épicé-poivré-intense-piquant
2. **Synergies fermenté-boisé** : Composés fermentés (Perique) + Humulene (Haschisch) → Profil fermenté-fruité-boisé-terreux
3. **Synergies noisette-fumé** : Pyrazines (Perique) + Sesquiterpènes oxydés (Haschisch) → Profil noisette-grillé-fumé-boisé-terreux
4. **Complexité maximale** : 4 synergies distinctes, profil très riche et complexe

**Profil global Perique + Haschisch Libanais/Algérien** : **Fermenté-fruité-prune-figue-épicé-poivré-boisé-terreux-noisette-fumé-acidulé-intense-puissant-complexe**

**Caractéristiques** :
- **Intensité maximale** : Profil extrêmement intense, puissant
- **Complexité maximale** : 4 synergies distinctes, profil très riche
- **Épicé-poivré dominant** : Notes épicé-poivré (Perique + Caryophyllene) très prononcées
- **Fermenté-fruité** : Notes fermenté-prune-figue (Perique) apportent complexité unique

## III. KENTUCKY FIRE-CURED : PROPRIÉTÉS ET COMPARAISON AVEC LATAKIA

### A. Kentucky Fire-Cured

**Origine** : Kentucky-Tennessee, États-Unis

**Méthode curing** : Stalk-cured + Fire-cured (14 jours)

**Bois fumage** : **Hickory** (caryer), **Oak** (chêne), **Maple** (érable)

**Composition chimique** :
- **Constituants phénoliques** : 25-28% de l'extrait CO2 (composés fumés)
- **Syringol** (lignine Syringyl) : Fumé-épicé-boisé-doux
- **Guaiacol** (lignine Guaiacyl) : Fumé-phénolique-médicinal (traces)
- **Ratio Syringyl/Guaiacyl** : Élevé (hardwoods) → Notes fumé-épicé-boisé-doux

**Profil aromatique** : **Fumé-BBQ-hickory-oak-maple-doux-épicé-boisé**

**Notes dominantes** :
1. **Fumé-BBQ** : Viandes fumées, BBQ, campfire
2. **Épicé-boisé** : Hickory, oak, maple, notes épicées-boisées
3. **Doux-sucré** : Notes doux-sucré (smoky & sweet note)

---

### B. Latakia

**Origine** : Syrie, Chypre (Moyen-Orient)

**Méthode curing** : Sun-cured + Smoke-cured

**Bois fumage** : Bois aromatiques + herbes (Moyen-Orient)

**Composition chimique** :
- **Composés fumés** : 1-3% (fumé-boisé-campfire-cuir)
- **Syringol + Guaiacol** : Fumé-épicé-boisé + Fumé-phénolique-médicinal
- **Ratio Syringyl/Guaiacyl** : Modéré → Notes fumé-campfire-cuir-piquant

**Profil aromatique** : **Fumé-boisé-campfire-cuir-terreux-piquant**

**Notes dominantes** :
1. **Fumé-campfire** : Campfire, feu de bois, cuir
2. **Terreux-boisé** : Terreux-tabac-fumé, boisé
3. **Piquant-intense** : Profil piquant, intense, complexe

---

### C. Comparaison Kentucky Fire-Cured vs Latakia

| Critère | Kentucky Fire-Cured | Latakia |
|---------|---------------------|---------|
| **Origine** | Kentucky-Tennessee, États-Unis | Syrie, Chypre (Moyen-Orient) |
| **Curing** | Stalk-cured + Fire-cured (14 jours) | Sun-cured + Smoke-cured |
| **Bois fumage** | Hickory, Oak, Maple (hardwoods) | Bois aromatiques + herbes (Moyen-Orient) |
| **Lignines** | Syringyl (dominant) | Guaiacyl + Syringyl |
| **Constituants phénoliques** | 25-28% (extrait CO2) | 1-3% (estimé) |
| **Profil** | Fumé-BBQ-hickory-oak-maple-doux-épicé | Fumé-campfire-cuir-boisé-terreux-piquant |
| **Intensité fumé** | Modérée-élevée | Élevée-très élevée |
| **Piquant** | Moins piquant, plus doux | Plus piquant, plus intense |
| **Notes** | Fumé-BBQ-viandes fumées-doux-sucré | Fumé-campfire-cuir-incense-complexe |
| **Caractère** | Fumé, BBQ, Doux, Épicé-boisé | Fumé, Campfire, Cuir, Piquant, Complexe |

---

### D. Avantages Kentucky Fire-Cured pour Accord 4

**Avantage 1 : Profil plus doux** 
- Kentucky Fire-Cured moins piquant que Latakia
- Notes fumé-BBQ-doux-sucré plus accessibles
- Profil fumé-épicé-boisé-doux (Syringol) vs fumé-campfire-cuir-piquant (Latakia)

**Avantage 2 : Notes BBQ-viandes fumées**
- Profil fumé-BBQ-hickory-oak-maple unique
- Synergie avec Perique (fermenté-fruité-prune) → Profil fumé-BBQ-fermenté-fruité
- Notes BBQ-viandes fumées + fermenté-prune = Profil "Smoked Meat & Prune"

**Avantage 3 : Ratio Syringyl/Guaiacyl élevé**
- Syringol (fumé-épicé-boisé-doux) dominant
- Profil fumé-épicé-boisé-doux plus harmonieux avec Perique (épicé-poivré-fermenté)
- Moins de notes phénoliques-médicinales (Guaiacol) que Latakia

**Avantage 4 : Constituants phénoliques élevés (25-28%)**
- Profil fumé très riche et intense
- Synergies avec Perique (composés phénoliques 1-3%) → Amplification notes fumé-épicé
- Synergies avec Haschisch (Caryophyllene, Humulene) → Profil fumé-épicé-boisé-terreux
