## II. SYNTHÈSE DES 3 ARTICLES PRIORITAIRES

### Article 1 : Chouvy (2025) - Réforme Politique Cannabis Maroc

**Contexte** :
- Réforme légale cannabis Maroc (Loi 13-21, adoptée 2021)
- Légalisation usages médicaux, cosmétiques, industriels
- Interdiction maintenue usages récréatifs

**Seuils THC** :
- THC < 1% : Cannabis "licite" (usage médical, cosmétique, industriel)
- THC > 1% : Cannabis "illicite" (usage récréatif interdit)

**Impact Production** :
- Encouragement cultivation cannabis CBD (THC < 1%)
- Maintien production haschisch traditionnel (THC > 1%, marché noir)
- Tension entre légalisation partielle et tradition

**Futur International** :
- Maroc = Potentiel exportateur cannabis légal (CBD)
- Concurrence internationale (Europe, Amérique du Nord)
- Maintien position haschisch traditionnel (marché noir)

**Pertinence PERFUMUM** :
- Contexte légal actuel production cannabis marocain
- Distinction cannabis CBD vs haschisch traditionnel
- Impact sur disponibilité et qualité haschisch marocain

---

### Article 2 : Bouhlal et al. (2024) - Transformation Cultivation Nord Maroc

**Analyse Géographique** :
- Nord Maroc (Rif, Ketama) = Zone principale cultivation cannabis
- Prohibition (1956-2021) → Légitimation partielle (2021-présent)
- Transformation pratiques agricoles (traditionnel → moderne)

**Cultivation Traditionnelle** :
- Variétés locales (landraces) adaptées climat Rif
- Cultivation extensive, faible irrigation, séchage soleil
- Production haschisch par tamisage à sec (dry sift)

**Cultivation Moderne** :
- Introduction variétés CBD (THC < 1%)
- Techniques irrigation modernes, serres
- Production extraits CBD (huiles, cosmétiques)

**Méthodes Fumage Traditionnelles** :
- Kif = Mélange cannabis + tabac noir local (75-80% / 20-25%)
- Sebsi = Pipe traditionnelle marocaine
- Méthode possiblement importée d'Inde (hypothèse)

**Pertinence PERFUMUM** :
- Méthodes cultivation traditionnelles vs modernes
- Variétés locales (landraces) vs variétés CBD
- Méthodes fumage traditionnelles (kif, sebsi)

---

### Article 3 : Hassan et al. (2023) - Caractérisation Chimique Haschisch

**Méthodologie** :
- Échantillons haschisch saisis Égypte (origine Maroc, Liban, Algérie)
- Analyse GC-MS (chromatographie gaz-spectrométrie masse)
- Identification terpènes et cannabinoïdes

**Résultats Terpènes** :
- **Haschisch Marocain** : β-Caryophyllène, α-Humulène, Myrcène, Limonène
- **Haschisch Libanais** : Myrcène, Limonène, β-Caryophyllène, Linalool
- **Haschisch Algérien** : Profil similaire au marocain

**Résultats Cannabinoïdes** :
- THC : 10-30% (variable selon origine et qualité)
- CBD : 0.5-3% (faible dans haschisch traditionnel)
- CBN : 0.5-2% (produit dégradation THC)

**Similitudes** :
- Les 3 échantillons (Maroc, Liban, Algérie) contiennent presque les mêmes terpènes et cannabinoïdes
- Variations quantitatives (proportions) mais profils qualitatifs similaires

**Pertinence PERFUMUM** :
- Profils terpéniques précis (GC-MS) haschisch Maroc et Liban
- Confirmation similitudes chimiques Maroc-Liban
- Données quantitatives pour formulations

## III. TABAC PERIQUE : PROPRIÉTÉS ET PROFIL

### A. Origine et Production

**Origine** : Louisiane, États-Unis (Paroisse de Saint James)

**Historique** :
- Cultivé par Acadiens (descendants colons français) depuis XVIIIe siècle
- Méthode fermentation unique (pression dans fûts chêne)
- Production limitée (< 100 tonnes/an), tabac rare et cher

**Variété** : Nicotiana tabacum, variété locale "Perique"

---

### B. Méthode Curing et Fermentation

**Étape 1 : Air-curing**
- Séchage air naturel (2-3 mois)
- Feuilles suspendues dans granges ventilées

**Étape 2 : Fermentation sous pression**
- Feuilles séchées placées dans fûts chêne (whisky bourbon)
- Pression appliquée (poids lourds sur couvercle fût)
- Fermentation anaérobie (sans oxygène) 1 an minimum
- Température : 20-30°C (température ambiante Louisiane)

**Étape 3 : Maturation**
- Maturation supplémentaire 1-2 ans (optionnelle)
- Développement profil aromatique complexe

**Durée totale** : 2-4 ans (air-curing + fermentation + maturation)

---

### C. Composition Chimique

| Composé | Teneur | Profil Aromatique |
|---------|--------|-------------------|
| **Nicotine** | 3-5% | Fort-nicotiné-puissant |
| **Sucres** | 0.5-2% | Faible-doux |
| **Acides organiques** | 5-10% | Acidulé-fermenté-vinaigré |
| **Composés fermentés** | 2-5% | Fermenté-fruité-prune-figue |
| **Pyrazines** | 0.02-0.08% | Noisette-grillé-fumé-intense |
| **Solanone** | 0.01-0.03% | Terreux-tabac-fumé-intense |
| **Composés phénoliques** | 1-3% | Épicé-poivré-piquant |

---

### D. Profil Aromatique Perique

**Profil global** : **Fermenté-fruité-prune-figue-épicé-poivré-terreux-fumé-fort-nicotiné-puissant**

**Notes dominantes** :
1. **Fermenté-fruité** : Prune, figue, fruits secs fermentés (acides organiques + composés fermentés)
2. **Épicé-poivré** : Poivre noir, piquant (composés phénoliques)
3. **Terreux-fumé** : Terreux-tabac-fumé-intense (pyrazines + solanone)
4. **Fort-nicotiné** : Nicotine élevée (3-5%), effet puissant

**Caractéristiques** :
- **Intensité extrême** : Profil très intense, puissant, ne se fume jamais pur
- **Complexité** : Profil complexe, fermenté-fruité-épicé-terreux
- **Dosage** : 5-15% maximum dans blends (condiment tabac)

---

### E. Synergies avec Latakia

**Latakia** : Fumé-boisé-campfire-cuir-terreux

**Perique** : Fermenté-fruité-prune-figue-épicé-poivré-terreux-fumé

**Synergies** :

1. **Composés fumés (Latakia) + Composés fermentés (Perique) → Fumé-Fermenté-Complexe**
   - Type : Synergie synergique
   - Composés fumés (fumé-boisé-campfire) + Composés fermentés (fermenté-fruité-prune) → Profil fumé-fermenté-complexe
   - Effet : Amplification notes fumé-fermenté, profil très riche

2. **Pyrazines (Latakia) + Pyrazines (Perique) → Noisette-Fumé-Intense**
   - Type : Synergie additive
   - Pyrazines Latakia (noisette-grillé-fumé) + Pyrazines Perique (noisette-grillé-fumé-intense) → Profil noisette-fumé-intense
   - Effet : Renforcement mutuel notes noisette-fumé, intensité maximale

3. **Composés fumés (Latakia) + Composés phénoliques (Perique) → Fumé-Épicé-Poivré**
   - Type : Synergie synergique
   - Composés fumés (fumé-cuir) + Composés phénoliques (épicé-poivré-piquant) → Profil fumé-épicé-poivré
   - Effet : Amplification notes fumé-épicé-poivré, profil piquant

4. **Solanone (Latakia) + Solanone (Perique) → Terreux-Fumé-Profond-Intense**
   - Type : Synergie additive
   - Solanone Latakia (terreux-tabac-fumé) + Solanone Perique (terreux-tabac-fumé-intense) → Profil terreux-fumé-profond-intense
   - Effet : Renforcement mutuel notes terreux-fumé, profondeur maximale

**Profil Latakia + Perique** : **Fumé-fermenté-épicé-poivré-terreux-noisette-campfire-cuir-prune-figue-profond-intense-puissant**

**Caractéristiques** :
- **Intensité maximale** : Profil extrêmement intense, puissant
- **Complexité maximale** : 4 synergies distinctes, profil très riche et complexe
- **Profondeur maximale** : Notes fumé-fermenté-terreux-épicé, profondeur extrême
