# PERFUMUM — essais physiques autonomes

Chaque sous-dossier est **autonome** : double-cliquez sur son `index.html` dans Chromium. Aucun serveur, build, paquet Node ou connexion à la base n’est requis. Chaque page contient un export documentaire embarqué et le même export est présent à côté sous le nom `fleur-fantome-2026-09-15.json` pour inspection et archivage.

| Dossier | Fonction | Interaction | Limite non négociable |
|---|---|---|---|
| `01-graphe-anamorphique` | Graphe recette–molécule projetable | Poignées de calibration, journal CSV | Ne corrige pas une géométrie 3D complexe. |
| `02-graphe-proximite` | Visualisation de distance Arduino ou curseur | Bouton Web Serial, curseur de repli | Aucune identité ni commande vers l’Arduino. |
| `03-champ-noir` | Champ de particules documentaire | Touches 1–8 ou boutons | Sans fumée, brume, diffusion ou combustion. |
| `04-partition-thermique` | Comparaison mesure ↔ points d’ébullition | Saisie/capteur série, journal CSV | Ce n’est pas une mesure de composition de l’air et la page ne commande aucun chauffage. |

Les CSV téléchargés restent locaux. Conservez-les avec une photo ou une courte vidéo de séance ; ne les importez pas automatiquement dans la base PERFUMUM.

La compatibilité de Web Serial dépend de Chromium sur ordinateur et de l’autorisation explicite de l’opérateur. Les trois autres essais sont pleinement utilisables sans port série.
