# PERFUMUM — Roadmap Stratégique 2026-2036

## Vision du Projet

PERFUMUM est une plateforme de recherche olfactive destinée à centraliser, organiser et analyser les données sur les molécules aromatiques, les plantes, les terroirs et les formulations. Ce projet s'inscrit dans une perspective de 10 ans de développement continu.

---

## État Actuel (Janvier 2026)

### Infrastructure Technique
- **198 pages/composants React** développés
- **110 tables** dans la base de données MySQL
- **Architecture tRPC** pour les API typées
- **Système d'authentification** Manus OAuth intégré
- **Tests Vitest** : 364+ tests passés
