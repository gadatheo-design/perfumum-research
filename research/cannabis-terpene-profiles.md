# Profils Terpéniques du Cannabis — Données Scientifiques

**Source** : The Cannabis Terpenes (NIH/PMC, 2020)
**DOI** : 10.3390/molecules25245792
**Auteurs** : Sarana Rose Sommano, Chuda Chittasupho, Warintorn Ruksiriwanich, Pensak Jantrawut

## Monoterpènes majeurs (10C)

Selon la recherche scientifique, les monoterpènes majeurs du cannabis incluent :

| Terpène | Fonction | Profil |
|---------|----------|--------|
| **Limonène** | Citron, agrumes | Majeur dans sativa |
| **β-Myrcène** | Terreux, herbacé | Majeur dans indica |
| **α-Pinène** | Sapin, boisé | Présent dans les deux |
| **Linalool** | Floral, lavande | Traces à modéré |
| **α-Terpinolène** | Herbal, épicé | Traces |
| **trans-Ocimène** | Sucré, herbacé | Traces |

## Sesquiterpènes majeurs (15C)

| Terpène | Fonction | Profil |
|---------|----------|--------|
| **E-Caryophyllène** | Épicé, poivré | Majeur |
| **Caryophyllène oxide** | Boisé, terreux | Majeur |
| **E-β-Farnesène** | Sucré, floral | Présent |
| **β-Caryophyllène** | Poivré, épicé | Majeur |

## Profils typiques par type

### Indica
- Myrcène dominant (20-35%)
- β-Caryophyllène (10-20%)
- Limonène (5-15%)
- Profil : Terreux, herbacé, relaxant

### Sativa
- Limonène dominant (15-30%)
- Myrcène (10-20%)
- α-Pinène (5-15%)
- Profil : Citronné, énergisant, clair

## Notes importantes

1. **Plus de 200 volatiles** ont été identifiés dans différents génotypes de cannabis
2. **58 monoterpènes** et **38 sesquiterpènes** ont été caractérisés
3. Les terpènes représentent **~25% de tous les métabolites**
4. La combinaison de terpènes crée les arômes uniques de chaque souche
5. Les cannabinoïdes sont synthétisés à partir de structures diterpéniques

## Recommandations pour l'enrichissement

Pour les variétés de cannabis sans profil complet :
- Utiliser les profils indica/sativa comme base
- Ajouter les terpènes majeurs avec pourcentages typiques
- Inclure les sesquiterpènes secondaires
- Ajouter les traces de monoterpènes spécialisés
