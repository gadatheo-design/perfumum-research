## Contenu identifié

### I. Objectif du volume
Méthode claire et reproductible pour :
- Créer, consigner et stabiliser des lots de compositions aromatiques
- Contrôler la cohérence entre versions (répétabilité)
- Assurer la qualité olfactive et chimique sur plusieurs séries
- Permettre l'évolution maîtrisée de chaque formule

### II. Organisation du laboratoire artisanal

**Espace minimal requis** :
- Zone propre : Pesée/formulation (surface lisse, 20-22°C)
- Zone d'observation : Test sensoriel (éclairage neutre, ventilation douce)
- Zone stockage : Matières premières (flacons ambrés, 15-18°C, sans lumière)

**Matériel essentiel** :
- Balance de précision (0.001 g)
- Agitateur magnétique et plaque chauffante (30-45°C max)
- Verrerie (béchers, pipettes, entonnoirs, flacons brunis)
- Carnet de lot (papier ou numérique)
- Étiqueteuse neutre
- Chronomètre et thermomètre digital
- Gants nitrile, masques, lunettes (sécurité chimique)

### III. Structure d'un dossier de lot

Chaque lot documenté comme entité autonome :

**Exemple de fiche type** :
| Champ | Exemple |
|-------|---------|
| Code lot | CHS-2025-01 |
| Nom du profil | Cheese chaud lactonique |
| Date formulation | 15.02.2025 |
| Formulateur | Atelier A. |
| Base support | Résine CBD + MCT |
| Poids total | 30 g |
| Température de travail | 33 °C |
| Composition détaillée | (voir section IV) |
| Observations olfactives | Fromagé, beurré, fond boisé |
| Stabilité testée J+30 | OK |
| Rendement / Perte | 0.4 % |

### IV. Protocole de formulation standardisé

**ÉTAPE 1 – PRÉPARATION**
- Nettoyer la verrerie à l'éthanol 95%
- Sécher à l'air libre 10 min
- Vérifier température de la pièce : 20-22°C
- Homogénéiser les matières premières (retour à température ambiante)

**ÉTAPE 2 – FORMULATION**
Peser chaque ingrédient avec précision de ±0.001 g. Respecter l'ordre suivant :
1. Support (huile, résine, cire)
2. Fixateurs lourds (indoles, lactones)
3. Cœur aromatique (acides gras, phénols)
4. Notes de tête (esters, terpènes)
5. Agiter à 300 rpm pendant 20 min
6. Chauffer si nécessaire à 35-40°C (jamais au-delà de 45°C)
7. Repos 24h avant test

**ÉTAPE 3 – CONTRÔLE**
- Test olfactif sur bande neutre à J+1, J+7, J+30
- Mesure de pH (si phase aqueuse)
- Observation visuelle (homogénéité, turbidité)
- Pesée finale : vérifier la perte ≤ 1%

**Résultat olfactif** : ouverture fruitée → cœur chaud → fond lactonique.  
**Tenue** : 8-10 h (test sur résine).

### VI. Codification des versions

Chaque modification de formule doit être codée pour suivre son évolution :

- `CHS-2025-01A` = version initiale
- `CHS-2025-01B` = ajout lactone
- `CHS-2025-01C` = réduction indole

**Règle** : Une version ne doit changer qu'un paramètre à la fois pour garder la lisibilité analytique.

### VII. Gestion des micro-lots

**Taille recommandée** :
- Prototype : 10-30 g
- Pré-série : 100-250 g
- Série limitée : 500-1000 g

Les micro-lots permettent d'expérimenter sans perte excessive de matière rare.

**Conservation** :
- Flacon ambré, fermeture PTFE, espace d'air minimal
- Stockage 15-18°C, sans lumière
- Contrôle à 1 mois / 3 mois / 6 mois

### VIII. Contrôle sensoriel

| Paramètre | Méthode | Seuil acceptable |
|-----------|---------|------------------|
| Intensité olfactive | Test bande | ±10% |
| Couleur | Observation visuelle | Variation légère tolérée |
| Texture | Viscosimètre / observation | Lisse, sans cristaux |
| Évolution | Test comparatif | Pas de rupture d'équilibre |
| Stabilité à 40°C (48h) | Test accéléré | Pas d'oxydation visible |

**Règle** : Toute variation supérieure à ±15% impose reformulation.

### IX. Enregistrement et archivage

Chaque lot terminé doit être :
- Étiqueté avec code, date, profil
- Consigné dans le registre principal
- Archivage des formules sur support double : papier + numérique
- Échantillon conservé en "musée olfactif" (1g, scellé, daté)

**Principe** : L'historique devient la bibliothèque sensorielle du créateur.
