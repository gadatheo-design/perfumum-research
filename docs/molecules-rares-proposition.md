# Proposition de Molécules Rares pour PERFUMUM

## Introduction

Cette liste propose une sélection de molécules rares et précieuses à intégrer dans la base de données PERFUMUM. Elle comprend trois catégories : les **matières premières naturelles rares**, les **molécules captives** des grandes maisons, et les **molécules de synthèse historiques**.

---

## 1. Matières Premières Naturelles Rares

### 1.1 Oud (Agarwood)
- **Origine** : Aquilaria (Asie du Sud-Est)
- **CAS** : 8016-20-4
- **Profil olfactif** : Boisé, animal, fumé, balsamique
- **Rareté** : Seulement 2-7% des arbres produisent de l'oud
- **Prix** : ~$30,000-50,000/kg
- **Note** : "Or liquide" de la parfumerie

### 1.2 Absolue d'Iris (Orris Butter)
- **Origine** : Iris pallida (Italie, Maroc)
- **CAS** : 8002-73-1
- **Profil olfactif** : Poudré, floral, terreux, violette
- **Rareté** : 3-6 ans de séchage, 500kg racines → 1kg huile
- **Prix** : ~$40,000-100,000/kg
- **Note** : La plus longue maturation en parfumerie

### 1.3 Ambre Gris (Ambergris)
- **Origine** : Cachalot (Physeter macrocephalus)
- **CAS** : 8038-65-1
- **Profil olfactif** : Marin, animal, musqué, boisé
- **Rareté** : Trouvé flottant en mer ou échoué
- **Prix** : ~$20,000-50,000/kg
- **Note** : "Or flottant" - substance la plus rare

### 1.4 Safran
- **Origine** : Crocus sativus (Iran, Inde, Espagne)
- **CAS** : 8022-66-2
- **Profil olfactif** : Épicé, cuiré, miel, métallique
- **Rareté** : 150,000 fleurs → 1kg de stigmates
- **Prix** : ~$5,000-15,000/kg
- **Note** : L'épice la plus chère au monde

### 1.5 Beurre d'Ambrette
- **Origine** : Hibiscus abelmoschus (Inde)
- **CAS** : 8015-62-1
- **Profil olfactif** : Musqué, floral, gras, poudré
- **Rareté** : Extraction complexe des graines
- **Prix** : ~$8,000-15,000/kg
- **Note** : Alternative végétale au musc animal

### 1.6 Santal de Mysore
- **Origine** : Santalum album (Inde)
- **CAS** : 8006-87-9
- **Profil olfactif** : Boisé crémeux, lacté, balsamique
- **Rareté** : 30 ans de croissance, espèce protégée
- **Prix** : ~$2,500-5,000/kg
- **Note** : Le santal le plus précieux

## 2. Molécules Captives des Grandes Maisons

### 2.1 Paradisone® (DSM-Firmenich)
- **CAS** : Captif
- **Profil olfactif** : Jasmin frais, citronné, transparent
- **Type** : Hedione haute performance
- **Usage** : Cœur de Hedione, fraîcheur jasminée

### 2.2 Ambrox® Super (DSM-Firmenich)
- **CAS** : 6790-58-5
- **Profil olfactif** : Ambre-boisé, musqué, minéral
- **Type** : Ambre gris synthétique premium
- **Usage** : Base ambrée, sillage puissant

### 2.3 Akigalawood® (Givaudan)
- **CAS** : Captif
- **Profil olfactif** : Boisé, épicé, patchouli fractionné
- **Type** : Fraction de patchouli par biochimie
- **Usage** : Notes boisées modernes

### 2.4 Clearwood® Prisma (DSM-Firmenich)
- **CAS** : Captif
- **Profil olfactif** : Patchouli propre, boisé, transparent
- **Type** : Patchouli biotechnologique
- **Usage** : Alternative durable au patchouli

### 2.5 Dreamwood™ Base (DSM-Firmenich)
- **CAS** : Captif
- **Profil olfactif** : Santal Mysore, crémeux, boisé
- **Type** : Reconstitution du santal indien
- **Usage** : Notes de santal authentiques

### 2.6 Nympheal™ (Givaudan)
- **CAS** : Captif
- **Profil olfactif** : Muguet aqueux, chèvrefeuille
- **Type** : Remplacement Lilial/Lyral (IFRA)
- **Usage** : Notes florales blanches

### 2.7 Mahonial® (Givaudan)
- **CAS** : Captif
- **Profil olfactif** : Muguet vert, magnolia
- **Type** : Alternative muguet post-IFRA
- **Usage** : Accords floraux verts

### 2.8 Cascalone® (DSM-Firmenich)
- **CAS** : Captif
- **Profil olfactif** : Marin, ozonic, pastèque
- **Type** : Calone amélioré
- **Usage** : Notes aquatiques modernes

### 2.9 Sinfonide® (IFF)
- **CAS** : Captif
- **Profil olfactif** : Poudré, musqué, peau
- **Type** : Musc poudré
- **Usage** : Effet seconde peau

### 2.10 Orcanox™ (Mane)
- **CAS** : Captif
- **Profil olfactif** : Ambre-boisé, sauge sclarée, labdanum
- **Type** : Alternative ambre gris
- **Usage** : Fond ambré naturel

## 3. Molécules de Synthèse Historiques

### 3.1 Coumarine
- **CAS** : 91-64-5
- **Profil olfactif** : Foin, tabac, amande, vanillé
- **Découverte** : 1868 (William Perkin)
- **Note** : Première molécule de synthèse en parfumerie

### 3.2 Calone 1951
- **CAS** : 28940-11-6
- **Profil olfactif** : Marin, iodé, pastèque, ozonic
- **Découverte** : 1951
- **Note** : Révolution des parfums aquatiques

### 3.3 Ionones (α, β, γ)
- **CAS** : 127-41-3 (α), 14901-07-6 (β)
- **Profil olfactif** : Violette, poudré, boisé, iris
- **Découverte** : 1893
- **Note** : Impossible à extraire naturellement

### 3.4 Héliotropine (Pipéronal)
- **CAS** : 120-57-0
- **Profil olfactif** : Amande, vanille, floral, poudré
- **Découverte** : 1869
- **Note** : Créée avant d'être trouvée dans la nature

### 3.5 Galaxolide®
- **CAS** : 1222-05-5
- **Profil olfactif** : Musc propre, poudré, floral
- **Découverte** : 1965 (IFF)
- **Note** : Musc polycyclique le plus utilisé

### 3.6 Iso E Super®
- **CAS** : 54464-57-2
- **Profil olfactif** : Boisé velouté, ambré, cèdre
- **Découverte** : 1973 (IFF)
- **Note** : "Molécule invisible" - effet peau

### 3.7 Ethyl Maltol
- **CAS** : 4940-11-8
- **Profil olfactif** : Caramel, praline, sucré
- **Usage** : Accords gourmands, 6x plus puissant que maltol

### 3.8 Cashmeran®
- **CAS** : 33704-61-9
- **Profil olfactif** : Musqué, boisé, épicé, ambré
- **Découverte** : 1970s (IFF)
- **Note** : Chaleur cachemire, très diffusif

### 3.9 Javanol®
- **CAS** : 198404-98-7
- **Profil olfactif** : Santal crémeux, boisé, lacté
- **Découverte** : 1990s (Givaudan)
- **Note** : Meilleure reconstitution du santal

### 3.10 Habanolide®
- **CAS** : 34902-57-3
- **Profil olfactif** : Musc macrocyclique, propre, animal
- **Découverte** : 1990s (Firmenich)
- **Note** : Musc le plus proche du naturel

## 4. Proposition de Gamme "Raretés"

### Structure suggérée

| Catégorie | Molécules | Thème |
|-----------|-----------|-------|
| **Trésors Naturels** | Oud, Iris, Ambre Gris, Safran | Matières précieuses millénaires |
| **Captives Modernes** | Paradisone, Akigalawood, Clearwood | Innovation des grandes maisons |
| **Pionnières** | Coumarine, Calone, Ionones | Molécules qui ont changé la parfumerie |
| **Muscs Précieux** | Galaxolide, Habanolide, Ambrette | Alternatives au musc animal |
| **Bois Rares** | Santal Mysore, Dreamwood, Javanol | Boisés crémeux et précieux |

### Accords Maîtres Suggérés

1. **Accord "Trésor d'Orient"** : Oud + Safran + Ambre Gris + Rose
2. **Accord "Iris Royal"** : Iris Absolue + Violette + Héliotropine + Ambrox
3. **Accord "Santal Sacré"** : Santal Mysore + Dreamwood + Javanol + Cashmeran
4. **Accord "Musc Précieux"** : Ambrette + Habanolide + Galaxolide + Iso E Super
5. **Accord "Océan Profond"** : Calone + Cascalone + Ambre Gris + Sel marin
