# Recherche APIs pour PERFUMUM - Notes

## 1. Fragella API (Parfums)
- **URL**: https://api.fragella.com/
- **Données**: 74k+ parfums avec notes (top, middle, base), accords (%), sillage, longévité, saison, occasion, prix
- **Tarification**: 
  - Free: 20 req/mois
  - Basic: $12/mois (5000 req)
  - Pro: $49/mois (20000 req)
  - Pay As You Go: $0.005/req
- **Intérêt pour PERFUMUM**: Données sur les parfums commerciaux, notes pyramidales, accords - pourrait enrichir les recettes et créer des liens entre molécules et parfums célèbres

## 2. AromaDb (Plantes aromatiques)
- **URL**: https://aromadb.cimapbioinfo.in/
- **Données**: 1321 structures chimiques aromatiques, bioactivités, 357 types de fragrances, 166 plantes commerciales
- **Accès**: Gratuit (académique)
- **Intérêt**: Enrichir les profils olfactifs, propriétés thérapeutiques

## 3. EssOilDB (Huiles essentielles)
- **URL**: https://ngdc.cncb.ac.cn/databasecommons/database/id/825
- **Données**: Compositions d'huiles essentielles, émissions volatiles
- **Accès**: Gratuit
- **Intérêt**: Compositions GC/MS des huiles essentielles

## 4. Flavornet (Composés aromatiques)
- **URL**: https://www.flavornet.org/
- **Données**: Composés aromatiques dans l'espace olfactif humain (<1000 odorants)
- **Accès**: Gratuit
- **Intérêt**: Descripteurs olfactifs, seuils de perception

## 5. Scent.vn Database
- **URL**: https://scent.vn/en/pages/compounds
- **Données**: Identifiants, profils olfactifs, propriétés chimiques, conformité IFRA
- **Intérêt**: Réglementation IFRA, sécurité des ingrédients



## 6. COCONUT (Produits Naturels)
- **URL**: https://coconut.naturalproducts.net/
- **Données**: 716,697 molécules de produits naturels, 70,896 organismes uniques, 124,690 citations
- **API REST**: Oui, accès temps réel
- **Accès**: Gratuit (open source)
- **Intérêt pour PERFUMUM**: Enrichir les molécules avec données de produits naturels, sources biologiques, voies biosynthétiques

## 7. IFRA Transparency List (Réglementation)
- **URL**: https://ifrafragrance.org/transparency-list
- **Données**: 3000+ ingrédients de parfumerie avec CAS, nom principal, catégorie naturels
- **API**: Non (scraping possible)
- **Intérêt**: Conformité réglementaire, limites d'utilisation, classification des ingrédients

## 8. ECHA CHEM (REACH - Chimie européenne)
- **URL**: https://chem.echa.europa.eu/
- **Données**: Données REACH sur les substances chimiques (toxicité, classification, étiquetage)
- **API**: Oui (European Chemicals Agency API)
- **Intérêt**: Données de sécurité, classification CLP, propriétés toxicologiques

## 9. CosIng (Cosmétiques UE)
- **URL**: https://single-market-economy.ec.europa.eu/sectors/cosmetics/cosmetic-ingredient-database_en
- **Données**: Base de données des ingrédients cosmétiques de l'UE
- **Intérêt**: Conformité cosmétique, restrictions d'usage

## 10. Open Beauty Facts
- **URL**: https://world.openbeautyfacts.org/data
- **Données**: Base collaborative de produits cosmétiques
- **API**: Oui (gratuite, open source)
- **Intérêt**: Données sur les produits finis, compositions réelles

## 11. Natural Products Atlas
- **URL**: https://www.npatlas.org/
- **Données**: Molécules de produits naturels avec structures
- **Intérêt**: Identification de molécules connues, exploration de séries structurelles

## 12. Perenual Plant API
- **URL**: https://perenual.com/docs/api
- **Données**: 10,000+ espèces de plantes avec images, données de culture
- **Accès**: Gratuit (avec limites)
- **Intérêt**: Enrichir les données botaniques des plantes aromatiques
