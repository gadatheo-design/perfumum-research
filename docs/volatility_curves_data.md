# Courbes de Volatilité - Données par Tabac

## Structure des Données

Chaque tabac possède des courbes de volatilité montrant l'évolution de l'intensité des composés en fonction de la température (80-180°C).

### Familles de Composés Tracées

1. **Terpènes** (vert) - Composés légers, volatils à basse température
2. **Aldéhydes** (bleu) - Composés frais, herbacés
3. **Lactones** (jaune) - Composés lactés, gourmands
4. **Pyrazines** (orange) - Composés grillés, chocolatés
5. **Phénols** (rouge) - Composés fumés, résineux

## Légende Intensité

- **0-20** : Trace
- **21-40** : Faible
- **41-60** : Modéré
- **61-80** : Fort
- **81-100** : Très fort

## Zones Critiques

- **Zone Basse (80-110°C)** : Terpènes, aldéhydes, profils frais
- **Zone Moyenne (110-140°C)** : Lactones, ionones, profils gourmands/floraux
- **Zone Haute (140-180°C)** : Pyrazines, phénols, profils fumés/grillés
