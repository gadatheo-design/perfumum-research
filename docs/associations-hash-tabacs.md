## PROTOCOLE DE MÉLANGE

1. **Préparation**: Émietter finement le tabac choisi
2. **Proportion**: Respecter les ratios recommandés (résine/tabac)
3. **Mélange**: Incorporer la résine émiettée au tabac
4. **Repos**: Laisser reposer 24h dans un contenant hermétique
5. **Maturation**: Pour un résultat optimal, attendre 3-7 jours
