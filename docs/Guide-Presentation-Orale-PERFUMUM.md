## Section 1 — Introduction et Contexte (2 minutes)

**Page : Accueil** `/`

### Points clés à aborder

PERFUMUM est une plateforme de recherche olfactive expérimentale développée sur une décennie (2025-2035). Le projet naît d'une conviction : l'olfaction reste le sens le moins documenté, le moins numérisé, le moins transmissible. Cette plateforme vise à créer un atlas multimédia de la connaissance olfactive, où chaque donnée devient une porte vers un autre chemin narratif.

Le laboratoire ABSORBE, basé à Berne, constitue le cœur opérationnel du projet. Les accords créés sont utilisés dans des projets artistiques site-specific et archivés selon une méthodologie scientifique rigoureuse.

### Chiffres à mentionner

- **556 molécules** documentées avec profils olfactifs complets
- **266 recettes** olfactives archivées
- **144 plantes** référencées avec leurs terroirs d'origine
- **10 ans** de recherche planifiée (2025-2035)

### Structure relationnelle (1.5 min)

La base de données PERFUMUM repose sur une architecture relationnelle où chaque entité est interconnectée. Les molécules constituent le noyau central, reliées aux plantes qui les produisent, aux terroirs où ces plantes poussent, et aux recettes qui les utilisent.

Démontrer sur le Hub des Molécules :
- Le système de filtrage par famille chimique (terpènes, aldéhydes, esters...)
- La recherche par profil olfactif (boisé, floral, épicé...)
- Les statistiques de couverture des données

### Fiche Molécule Détaillée (1.5 min)

Cliquer sur une molécule pour montrer :
- Le **radar de profil olfactif** (8 axes : intensité, diffusion, ténacité, etc.)
- Les **relations avec les plantes** sources
- Les **recettes** utilisant cette molécule
- Les **données scientifiques** (CAS, formule, masse molaire)

## Section 3 — Méthodologie ABSORBE (2 minutes)

**Page : Méthodologie** `/methodologie/absorbe`

### Le cadre scientifique

ABSORBE est l'acronyme de notre méthodologie : **A**nalyse, **B**ase de données, **S**ynergies, **O**lfaction, **R**echerche, **B**otanique, **E**xpérimentation.

Cette approche combine rigueur scientifique et sensibilité artistique. Chaque molécule est évaluée selon une échelle de notation standardisée de 0 à 10 sur huit dimensions olfactives.

### Points à souligner

- **Protocoles analytiques** : GC-MS pour l'identification moléculaire
- **Échelle de notation** : système cohérent permettant la comparaison
- **Documentation exhaustive** : chaque décision de formulation est archivée
- **Reproductibilité** : les recettes peuvent être reproduites avec précision

## Section 4 — Outils de Recherche et Visualisations (3 minutes)

**Pages : Synergies** `/suggestions-synergies` **puis Graphe** `/graphe-relations`

### Système de Synergies (1.5 min)

Le moteur de suggestions de synergies analyse les compatibilités chimiques et olfactives entre molécules. Il propose des associations basées sur :
- La complémentarité des profils olfactifs
- La compatibilité des familles chimiques
- Les associations validées historiquement

Démontrer une recherche de synergies pour une molécule spécifique (ex: linalol).

### Graphe de Relations (1.5 min)

La visualisation en graphe de force permet d'explorer le réseau de connexions :
- **Nœuds** : molécules, plantes, terroirs, recettes
- **Liens** : relations de composition, d'origine, d'utilisation
- **Filtres** : par type d'entité, par famille, par région

Montrer comment naviguer dans le graphe et découvrir des connexions inattendues.

## Section 6 — Contribution et Évolution (2 minutes)

**Page : Interface Contributeur** `/contributor`

### Système collaboratif

PERFUMUM est conçu pour accueillir des contributions externes. L'interface contributeur permet :
- **Ajout de molécules** avec détection automatique de doublons
- **Ajout de plantes** avec géolocalisation des terroirs
- **Création de liaisons** entre entités existantes
- **Workflow de validation** par les administrateurs

### Vision décennale

Le projet est pensé sur 10 ans. La structure flexible permet :
- L'intégration continue de nouvelles données
- L'évolution des méthodologies
- La collaboration avec d'autres laboratoires
- L'archivage pérenne des connaissances

## Section 7 — Conclusion (1 minute)

**Page : Dashboard** `/dashboard`

### Synthèse

PERFUMUM représente une tentative unique de documenter, structurer et transmettre la connaissance olfactive. La plateforme combine :
- **Rigueur scientifique** : données vérifiées, protocoles standardisés
- **Sensibilité artistique** : création de parfums site-specific
- **Vision long terme** : projet décennal avec archivage pérenne
- **Ouverture collaborative** : contribution externe encouragée

### Appel à l'action

Inviter l'audience à :
- Explorer la plateforme librement
- Contribuer leurs propres données
- Proposer des collaborations de recherche
- Suivre l'évolution du projet sur les 10 prochaines années
