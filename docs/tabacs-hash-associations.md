## Protocole de Mélange Hash + Tabac

### Méthode 1 : Mélange à sec (recommandé)

1. Émietter finement le hash/résine pétrichor
2. Mélanger avec le tabac coupé fin
3. Laisser reposer 24-48h dans un contenant hermétique
4. Le tabac absorbe les arômes de la résine

### Méthode 2 : Infusion

1. Placer le tabac dans un bocal
2. Ajouter des copeaux de résine pétrichor
3. Fermer hermétiquement
4. Laisser infuser 1-2 semaines à température ambiante
5. Retirer les copeaux de résine avant utilisation

### Méthode 3 : Couche (layering)

1. Placer une couche de tabac dans le foyer
2. Ajouter une fine couche de résine émiettée
3. Recouvrir d'une autre couche de tabac
4. La chaleur libère progressivement les arômes de la résine
