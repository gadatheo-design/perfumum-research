## Notes de Développement

### Synergies Identifiées

1. **Agrumes + Vétiver** : Italian Bergamot + Haitian Vetiver créent un équilibre frais-terreux classique
2. **Encens + Pétrichor** : Omani Frankincense + Mitti Attar évoquent la pluie sur terre sacrée
3. **Floraux + Ambre** : Neroli + Gris d'Ambre apportent luminosité et profondeur
4. **Vétiver x2** : Haitian Vetiver (notes de tête) + Black Emerald (vintage) offrent une palette complète
5. **Agrumes asiatiques** : Miyazaki Citrus + Makrut Lime créent une signature japonaise-thaïlandaise

### Recommandations de Maturation

- **Recettes C2** : 2-4 semaines de maturation pour harmoniser les notes résineuses
- **Recettes C3** : 1-2 semaines, les floraux s'épanouissent rapidement
- **Recettes C4** : 4-8 semaines minimum, les notes terreuses et ambrées nécessitent du temps
- **Expérimentales** : 3-6 semaines selon la complexité
