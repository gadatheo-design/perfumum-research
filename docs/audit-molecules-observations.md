# Observations - Page Molécules

## État actuel observé

La page des molécules affiche 366 molécules avec un système de filtres avancé comprenant des sliders pour les propriétés radar et chimiques.

### Points positifs
- Filtres par gamme (badges colorés)
- Filtres par famille chimique
- Filtres par profil olfactif (autocomplete avec 879 profils)
- Filtres par concentration
- Filtres radar (Intensité, Fraîcheur, Chaleur, Douceur, Épices, Terreux)
- Filtres propriétés chimiques (Point d'ébullition, Masse moléculaire)
- Mini radar hexagonal sur chaque carte
- Propriétés chimiques affichées (masse, volatilité, intensité, point d'ébullition)

### Points à améliorer
1. L'intensité affiche des valeurs incohérentes (48/10, 85/10, 79/10) - même problème que les recettes
2. Les cartes sont assez denses en informations
3. Certaines molécules ont "Formule non disponible" alors que d'autres ont la formule chimique
4. Les mini radars sont parfois vides (pas de données)
5. Pas de vue alternative (liste compacte)

### Données observées
- 366 molécules trouvées (vs 448 sur la page d'accueil - différence à investiguer)
- Familles chimiques variées : Non classé, Monoterpénol, Ambre synthétique, Organique/Cheese, etc.
- Propriétés complètes : masse moléculaire, volatilité, intensité, point d'ébullition

## Améliorations recommandées
- Corriger l'affichage de l'intensité (même correction que RecetteCard)
- Vérifier la cohérence du nombre de molécules entre les pages
- Compléter les formules chimiques manquantes
