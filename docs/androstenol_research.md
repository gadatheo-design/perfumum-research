# Androsténol - Fiche Molécule

## Identité Chimique
- **Nom IUPAC** : 5α-androst-16-en-3α-ol (3α,5α-androstenol ou 3α-androstenol)
- **Formule moléculaire** : C₁₉H₃₀O
- **Masse molaire** : 274.448 g/mol
- **CAS** : 1153-51-1
- **PubChem CID** : 101989
- **ChemSpider** : 92136
- **SMILES** : C[C@]12CC[C@H]3[C@H]([C@@H]1CC=C2)CC[C@@H]4[C@@]3(CC[C@H](C4)O)C

## Classification
- **Famille chimique** : Stéroïde (classe 16-androstène)
- **Type** : Phéromone et neurostéroïde
- **Origine** : Endogène (humains, porcs, mammifères)

## Propriétés Olfactives
- **Odeur caractéristique** : Musquée (musk-like)
- **Présence naturelle** : Truffes noires (Tuber melanosporum), salive de porc mâle
- **Contribution** : Odeur axillaire humaine

## Biosynthèse
- Synthétisé dans les testicules (humains et porcs)
- Également dans les glandes surrénales et ovaires
- Peut être synthétisé dans la muqueuse nasale humaine
- Voie : Prégnénolone → Androstadienol → Androstadienone → Androstenone → Androstenol

## Activité Biologique
- **Modulateur positif du récepteur GABA-A** (puissant)
- Effets anxiolytiques, antidépresseurs, anticonvulsivants (chez les animaux)
- Modifie les réponses comportementales et sociales humaines
- Diminue la fréquence des pulses de LH pendant la phase folliculaire
- Impliqué dans la synchronisation menstruelle
- Activité androgène minimale ou nulle

## Présence dans le Corps Humain
- Urine (quantités considérables)
- Plasma sanguin
- Salive
- Sueur axillaire
- Système nerveux central (traverse la barrière hémato-encéphalique)

## Stéréoisomère
- 3β-androstenol (5α-androst-16-en-3β-ol) : également endogène, contribue à l'odeur axillaire mais ne potentialise pas le récepteur GABA-A
