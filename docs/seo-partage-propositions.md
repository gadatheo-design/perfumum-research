### **Balises communes (toutes pages)**

```html

<meta property="og:site_name" content="PERFUMUM — Recherche Olfactive" />
<meta property="og:locale" content="fr_FR" />
<meta property="og:type" content="website" />

<!-- Twitter Cards -->
<meta name="twitter:card" content="summary_large_image" />

## 📸 IMAGE PREVIEW (OpenGraph)

L'image OpenGraph doit être **1200×630 pixels** (format recommandé par Facebook/LinkedIn/Twitter).

### **Spécifications techniques**
- **Dimensions** : 1200×630 px (ratio 1.91:1)
- **Format** : JPG ou PNG
- **Poids** : < 1 MB
- **Contenu** : Logo PERFUMUM + tagline + visuel représentatif

### **Proposition de design**

```
┌────────────────────────────────────────────────┐

## 📊 CHECKLIST D'IMPLÉMENTATION

### **Balises HTML (dans `<head>`)**
- [ ] Ajouter `<title>` unique pour chaque page
- [ ] Ajouter `<meta name="description">` pour chaque page
- [ ] Ajouter balises OpenGraph (`og:title`, `og:description`, `og:image`, `og:url`)
- [ ] Ajouter balises Twitter Cards (`twitter:card`, `twitter:title`, `twitter:description`, `twitter:image`)
- [ ] Ajouter `<link rel="canonical">` pour éviter le contenu dupliqué

### **Images OpenGraph**
- [ ] Créer image 1200×630 px pour la home
- [ ] Créer images spécifiques pour /molecules, /recettes, /gammes
- [ ] Héberger les images sur le serveur (dossier `/public/og/`)
- [ ] Tester les images avec [Facebook Debugger](https://developers.facebook.com/tools/debug/)
- [ ] Tester les images avec [Twitter Card Validator](https://cards-dev.twitter.com/validator)

### **Fichiers techniques**
- [ ] Créer `robots.txt` (autoriser indexation)
- [ ] Créer `sitemap.xml` (lister toutes les pages)
- [ ] Ajouter balise `<meta name="robots" content="index, follow">`
- [ ] Configurer Google Search Console
- [ ] Configurer Google Analytics (si souhaité)
