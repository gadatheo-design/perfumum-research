# Données Phéromones Humaines

## Androsténone (5α-androst-16-en-3-one)
- **Formule chimique** : C₁₉H₂₈O
- **Masse moléculaire** : 272.432 g/mol
- **CAS** : 18339-16-7
- **Classe** : 16-androstène stéroïdien
- **Profil olfactif** : Variable selon génotype - urineux/sudoral (désagréable), boisé, ou floral/vanillé (agréable)
- **Sources naturelles** : Salive de verrat, céleri, truffe
- **Biosynthèse** : Produit à partir de l'Androstadienone par 5α-réductase
- **Seuil de détection** : 0.2 ppb à 0.2 ppm (très variable)
- **Récepteur** : OR7D4 (polymorphisme génétique)

## Androstadienone (androsta-4,16-dien-3-one)
- **Formule chimique** : C₁₉H₂₆O
- **Masse moléculaire** : 270.416 g/mol
- **CAS** : 4075-07-4
- **Classe** : 16-androstène stéroïdien
- **Profil olfactif** : Musqué, légèrement sucré, subtil
- **Sources naturelles** : Sueur axillaire masculine, peau
- **Biosynthèse** : Produit à partir de l'Androstadienol par 3β-hydroxystéroïde déshydrogénase
- **Effets documentés** : Réduction nervosité/tension chez femmes hétérosexuelles
- **Précurseur de** : Androsténone (via 5α-réductase)

## Androsténol (3α-androst-16-en-3-ol) - Déjà dans la base
- **Formule chimique** : C₁₉H₃₀O
- **Masse moléculaire** : 274.44 g/mol
- **Profil olfactif** : Musqué, terreux, truffe, boisé
- **Sources naturelles** : Truffe noire, sueur fraîche
- **Biosynthèse** : Produit à partir de l'Androsténone par 3-cétostéroïde réductase

## Relations biosynthétiques
```
Androstadienol → Androstadienone → Androsténone → Androsténol
                (3β-HSD)          (5α-réductase)  (3-cétostéroïde réductase)
```
