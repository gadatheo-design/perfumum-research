## Développement de Profils Terpéniques pour Résines et Extraits Naturels

## Structure Identifiée

### I. Introduction Générale
**Objectif** : Documenter la base chimique et sensorielle des profils aromatiques du tabac et cannabis pour application dans formulations de résines CBD, extraits aromatiques et huiles parfumées.

### II. Les 4 Familles Chimiques Fondamentales

#### 1. **Acides Gras** (Composés lipidiques à faible volatilité)
**Rôle** : Vecteurs de rondeur, chaleur et densité olfactive

**Molécules identifiées** :
- **Hexanoïque** : Formation de lactones et aldéhydes → Fromage, beurre, fruit mûr
- **Octanoïque** : Pyrolyse → acides capryliques → Fromage fort, cuir chaud
- **Décanoïque** : Résistant, forme des lactones → Crémeux, doux, noix
- **Linoléique** : Oxydation → aldéhydes → Vert, noisette, fumé léger
- **Oléique** : Aldéhydes gras (hexanal, nonanal) → Doux, beurré, feuille séchée

#### 2. **Acides Aromatiques** (Issus des polyphénols)
**Rôle** : Dimension balsamique, vanillée et fumée

**Molécules identifiées** :
- **Benzoïque** : Décarboxylation → phénols simples → Balsamique, médicinal
- **Cinnamique** : Condensation → styrène → Doux, vanillé
- **Caféique** : Fragmentation → guaiacol → Fumé, bois sec
- **Férulique** : Oxydation → vanilline → Boisé, vanillé
- **Coumarique** : Cyclisation → coumarine → Foin, miel

#### 3. **Esters** (Volatils et sucrés)
**Rôle** : Nuances fruitées, florales et lactoniques

**Molécules identifiées** :
- **Éthyl butyrate** : Fruité, sucré → Ananas, pomme
- **Isoamyl acetate** : Fruité-lactonique → Banane, poire
- **Benzyl acetate** : Floral-suave → Jasmin, miel
- **Éthyl hexanoate** : Fruit gras → Fromage doux, pomme
- **Ethyl lactate** : Crémeux → Lait, yaourt

#### 4. **Indoles et Dérivés Azotés**
**Rôle** : Molécules puissantes à effet animal, floral noir ou "cuir chaud"

**Molécules identifiées** :
- **Indole** : Azoté hétérocyclique → Jasmin noir, animal, cuir
- **Skatole** : Azoté hétérocyclique → Fumier noble, truffe, viande grillée
- **Methyl anthranilate** : Ester azoté → Raisin, fleur d'oranger, sucré
- **Indoline** : Réduit → Doux, poudré, cireux

### III. Réactions Thermiques
Chaque famille engendre des sous-produits aromatiques par :
- **Fermentation** : Transformation biologique
- **Pyrolyse** : Décomposition thermique

Ces réactions expliquent la complexité olfactive comparable à celle d'un vin ou fromage affiné.
