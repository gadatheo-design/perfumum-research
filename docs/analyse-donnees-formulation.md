# Analyse du Fichier de Données — Formulation Résines CBD & Terpènes

Ce document analyse le contenu du fichier partagé et évalue son intérêt pour le projet PERFUMUM.

---

## Résumé du Contenu

Le fichier contient **7 sections majeures** de données R&D sur la formulation de résines CBD aromatiques :

### 1. Manuel Indole & Skatole
- **3 gammes** de profils aromatiques (Animal/Tabac/Oud, Floral/Jasmin, Hybrides)
- **6 formules** avec dosages précis (0.001-0.05%)
- Procédures techniques de dilution et maturation

### 2. Gamme "Cheese Terpenic Line"
- Chimie complète du profil "Cheese" (acides gras C6-C10, cétones)
- **5 déclinaisons** : Classic, Tropical, Blue, Smoky, Sweet Cheese
- Méthode d'intégration artisanale détaillée

### 3. Gamme "Ester Lab"
- **6 profils** esters aromatiques (Velvet Fruit, Cassis Blanc, Butter Flower, etc.)
- Base technique avec pH optimal et maturation

### 4. Acides Gras Aromatiques du Tabac
- **10 acides gras** avec profils olfactifs (C6 à C18)
- Tableaux de présence par type de tabac (Burley, Virginia, Cigare)
- Applications suggérées pour résines CBD

### 5. Esters Aromatiques du Tabac
- **13 esters** avec rôles olfactifs détaillés
- Interprétation sensorielle par type de tabac
- **5 compositions test** prêtes à l'emploi

### 6. Synergies Terpènes × Molécules Niches
- Explication détaillée des axes olfactif et technique
- Rôle des fixateurs (Ambroxan, Labdanum, Styrax)

### 7. Profils Aromatiques d'Exception
- **Cuir Marin** : Limonène + Tabac Blond + Ambroxan
- **Forêt de Cacao** : Bornéol + Cacao + Mousse de Chêne
- **Fleur Fantôme** : Profil floral abstrait
- Formulations complètes avec proportions (100g)
