# Test du filtre par classe chimique - 04 Jan 2026

## Résultat du test

Le filtre par classe chimique fonctionne correctement :

1. **Sélecteur ajouté** : Un nouveau sélecteur "Classe chimique" est disponible à côté du filtre "Famille olfactive"
2. **Options disponibles** : 
   - Tous
   - Alcool
   - Aldéhyde
   - Aromatique
   - Coumarine
   - Diterpène
   - Ester
   - Éther
   - Cétone
   - Monoterpène
   - Musc
   - Autre
   - Phénol
   - Sesquiterpène

3. **Chip de filtre actif** : Quand un filtre est sélectionné (ex: Monoterpène), un chip "Classe: Monoterpène" apparaît dans la barre des filtres actifs

4. **Filtrage fonctionnel** : Seules les molécules de la classe sélectionnée sont affichées
