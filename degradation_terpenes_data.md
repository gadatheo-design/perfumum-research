# Dégradation des Terpènes - Données Scientifiques

## 1. Voies de Dégradation Thermique

### 1.1 Pyrolyse (> 200°C)
**Terpènes concernés** : Limonène, α-Pinène, β-Caryophyllène, Myrcène

**Mécanismes** :
- Rupture de liaisons C-C
- Déshydrogénation
- Cyclisation intramoléculaire

**Produits principaux** :
- **Limonène** → p-Cymène, Terpinolène, α-Terpinène
- **α-Pinène** → Camphène, Limonène, Terpinolène
- **β-Caryophyllène** → Caryophyllène oxide, Humulène
- **Myrcène** → Linalool, Géraniol, Nérol

### 1.2 Isomérisation (120-180°C)
**Terpènes concernés** : α-Pinène, Limonène, Linalool

**Mécanismes** :
- Réarrangement squelettique
- Migration de double liaison
- Équilibre thermodynamique

**Produits principaux** :
- **α-Pinène** ⇌ Camphène ⇌ Limonène
- **Limonène** ⇌ Terpinolène ⇌ α-Terpinène
- **Linalool** ⇌ Géraniol ⇌ Nérol

### 1.3 Cyclisation (140-200°C)
**Terpènes concernés** : Myrcène, Linalool, Géraniol

**Mécanismes** :
- Formation de cycles à 6 membres
- Attaque électrophile intramoléculaire
- Catalyse acide

**Produits principaux** :
- **Myrcène** → α-Terpinène, γ-Terpinène
- **Linalool** → α-Terpinéol, Limonène
- **Géraniol** → Citronellol, α-Terpinéol

## 2. Voies de Dégradation Oxydative

### 2.1 Auto-oxydation (20-80°C, O₂)
**Terpènes concernés** : Tous les terpènes insaturés

**Mécanismes** :
- Formation de radicaux libres
- Addition d'oxygène sur double liaison
- Propagation en chaîne

**Produits principaux** :
- **Limonène** → Limonène-1,2-époxide, Carvone, Carveol
- **α-Pinène** → Pinène oxide, Verbenone, Verbenol
- **Myrcène** → Myrcène oxide, Linalool oxide
- **Linalool** → Linalool oxide (furanoid/pyranoid)

### 2.2 Photo-oxydation (UV + O₂)
**Terpènes concernés** : Terpènes conjugués (β-Caryophyllène, Humulène)

**Mécanismes** :
- Oxygène singulet (¹O₂)
- Addition [4+2] de Diels-Alder
- Formation d'endoperoxydes

**Produits principaux** :
- **β-Caryophyllène** → Caryophyllène endoperoxide, β-Caryophyllène oxide
- **Humulène** → Humulène epoxide I, II, III
- **Limonène** → Limonène hydroperoxide, Ascaridole

### 2.3 Oxydation Enzymatique (conditions biologiques)
**Terpènes concernés** : Monoterpènes hydroxylés

**Mécanismes** :
- Cytochrome P450
- Hydroxylation régiosélective
- Formation d'alcools, cétones, acides

**Produits principaux** :
- **Linalool** → 8-Hydroxylinalool, Acide linaloolique
- **Géraniol** → 8-Hydroxygéraniol, Acide géranique
- **α-Terpinéol** → 7-Hydroxy-α-terpinéol

## 4. Facteurs Influents

### 4.1 Température
- **< 100°C** : Dégradation lente, principalement oxydative
- **100-180°C** : Isomérisation dominante, début de pyrolyse
- **180-250°C** : Pyrolyse active, formation de produits aromatiques
- **> 250°C** : Décomposition totale, formation de composés carbonés

### 4.2 Oxygène
- **Absence d'O₂** : Pyrolyse pure, isomérisation
- **O₂ atmosphérique** : Auto-oxydation lente (jours-semaines)
- **O₂ enrichi** : Oxydation rapide, formation d'oxydes

### 4.3 Catalyseurs
- **Acides** : Accélèrent isomérisation et cyclisation
- **Bases** : Favorisent élimination et rétro-aldolisation
- **Métaux** : Catalysent hydrogénation et déshydrogénation

### 4.4 Solvants
- **Apolaires** : Stabilisent terpènes, ralentissent oxydation
- **Polaires** : Favorisent réactions ioniques
- **Eau** : Hydrolyse, formation d'alcools tertiaires

## 5. Applications Pratiques PERFUMUM

### 5.1 Contrôle de la Dégradation
- **Stockage** : Température < 20°C, absence de lumière, atmosphère inerte (N₂)
- **Manipulation** : Éviter chauffage prolongé > 140°C
- **Formulation** : Ajout d'antioxydants (tocophérol, BHT)

### 5.2 Exploitation de la Transformation
- **Vieillissement contrôlé** : 60-80°C, 7-14 jours → Oxydation partielle (notes miel, cire)
- **Chauffage modéré** : 140-160°C, 10-20 min → Isomérisation (complexité aromatique)
- **Pyrolyse ciblée** : 200-220°C, 5-10 min → Formation p-cymène (notes épicées)

### 5.3 Stabilisation des Recettes
- **Terpènes sensibles** : Myrcène, Linalool → Utiliser formes oxydées (linalool oxide)
- **Terpènes stables** : α-Pinène, Limonène → Base de formulation
- **Synergies** : Mélanger terpènes oxydés + non-oxydés → Profil évolutif
